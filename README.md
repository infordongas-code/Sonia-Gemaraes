# Projeto de Vida — Tayla, Evilin & Nathiely

Projeto web desenvolvido em **HTML5**, **CSS3** e **JavaScript** puro, pronto para ser aberto e executado no **Visual Studio Code (VS Code)**.

## Integrantes e Carreiras
- **Tayla:** Advocacia (Direito)
- **Evilin:** Medicina Veterinária
- **Nathiely:** Pediatria (Medicina)

## Como abrir no VS Code
1. Extraia a pasta do arquivo `.zip`.
2. Abra o **VS Code**, clique em **Arquivo > Abrir Pasta** e selecione a pasta extraída.
3. Clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server** (ou abra o `index.html` diretamente no navegador).
